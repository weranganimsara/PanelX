REST API Documentation

Connect your Paid Site or Bot directly to PanelX for automated account creation

1. Health Check Endpoint

curl -X GET http://YOUR_VPS_IP:7788/api/health \ -H "x-api-key: YOUR_SECRET_KEY"

2. Create Client Account

curl -X POST http://YOUR_VPS_IP:7788/api/user/create \ -H "Content-Type: application/json" \ -H "x-api-key: YOUR_SECRET_KEY" \ -d '{ "username": "customer101", "password": "pass1234", "days": 30, "bandwidthGB": 100, "simultaneousLimit": 3 }'

3. SG Home Paid Site (.env) Setup

FALCON_API_URL=http://YOUR_VPS_IP:7788 FALCON_API_KEY=SG_HOME_FALCON_SECRET_2026
